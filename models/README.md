# Models Directory

This directory stores serialized model artifacts and evaluation summaries generated by the training pipeline (`train.py`).

## Saved Artifacts:
- `tfidf_vectorizer.joblib`: Serialized `TfidfVectorizer` fitted on training corpus.
- `naive_bayes.joblib`: Trained `MultinomialNB` model.
- `logistic_regression.joblib`: Trained `LogisticRegression` model.
- `linear_svm.joblib`: Trained `CalibratedClassifierCV(LinearSVC)` model.
- `evaluation_metrics.json`: JSON summary of model accuracy, precision, recall, and F1-scores.

Models can be re-generated anytime by running:
```bash
python train.py
```
